## Design and acceptance

Repair the existing owners rather than add a parallel marketing system. Keep SFP's canonical release and SMTP composition as the current-package execution authority. Share generic campaign merge semantics across contact, prospect and preview paths, reject unsupported tokens before approval and dispatch, and prevent generic campaign activation from bypassing SFP's release. Add an opt-in sequences-only capability without changing any profile settings or enabling legacy producers.

Extend the versioned five-target classifier with curated exact returned-provider labels. Preserve geography, DBPR and ambiguity boundaries; never infer eligibility from the search query. Retained recovery must re-evaluate immutable artifacts through existing import identities without repurchasing or duplicating rows.

Consolidate accepted-form conversion events behind the existing consent owner, with receipt-based replay suppression and explicit Google Ads destinations. Use direct Vite environment properties so IDs compile into the client; never invent account IDs. Report tracking configuration and observed attribution separately. Suppress unsolicited vendor chat over conversion forms while retaining deliberate help access. Default package screens to current content, distinguish unavailable catalog state from empty results, and correct misleading readiness diagnostics.
