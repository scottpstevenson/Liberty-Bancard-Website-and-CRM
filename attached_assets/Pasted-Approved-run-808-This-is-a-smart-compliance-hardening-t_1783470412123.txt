This must be independent from SESSION_SECRET so unsubscribe links remain valid even if the session secret is rotated.

Required secret quality

Use a strong random value.

Acceptable examples:

openssl rand -base64 48

or another cryptographically secure random generator.

Do not use:

LibertyBancard
unsubscribe-secret
same value as SESSION_SECRET
short manually typed phrase
test fallback string

Because Liberty has not launched real outreach yet, this should be safe.
