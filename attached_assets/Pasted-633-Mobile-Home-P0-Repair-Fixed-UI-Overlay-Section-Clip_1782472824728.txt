What & Why

The latest mobile Home page is failing because fixed UI is covering content and desktop sections are still being stacked into a massive mobile scroll.

Visible failures from screenshots:

* section headings start behind the sticky header/disclaimer/nav stack
* “The Deliverable” / “Choose the Strategy” / other headings are visibly clipped
* bottom CTA dock covers report cards, table rows, cards, CTAs, and body copy
* chat bubble covers Book CTA, red-flag cards, report cards, proof cards, terminal section, vertical cards, and body copy
* bottom CTA still renders as three equal app-tab-style columns: Call / Book / Upload
* mobile page still requires far too many screens
* terminal comparison table is unusable on mobile
* vertical cards are still huge stacked blocks
* offer cards are too tall and clipped
* calculator/estimate section is split awkwardly and gets covered
* How It Works still shows oversized step blocks and a second timeline
* internal platform/operations section still appears in the mobile path and gets covered
* final content cannot breathe because sticky UI consumes too much viewport

This cannot ship.

⸻

Core Goal

Fix mobile Home so:

No meaningful content is hidden behind the fixed header, sticky CTA, chat bubble, browser safe area, or bottom dock.

The mobile Home page must become:

a focused merchant conversion path

not:

the full desktop website stacked vertically under floating UI

Non-Negotiable Acceptance Criteria

This task passes only if all are true:

1. No section heading is clipped behind the sticky header/disclaimer/nav.
2. No card text, CTA, form field, table row, or section body is covered by the bottom dock.
3. Chat bubble does not overlap readable content or CTAs.
4. Bottom CTA is no longer three equal app-tab columns.
5. Upload is the dominant mobile action.
6. Mobile content is meaningfully compressed.
7. Tables are converted to mobile-friendly cards/accordions.
8. The Home page no longer requires 25–30 screenshots at 390px.
9. The page has mobile-specific variants instead of stacking every desktop section.

P0 Fix 1 — Header Stack Must Stop Clipping Section Starts

Current problem:

Section content begins underneath the header/disclaimer/nav stack. In screenshots, section labels/headings are hidden behind the header.

Fix requirements:

* calculate actual mobile header stack height
* add global/mobile CSS variable if useful, e.g. --mobile-header-offset
* add scroll-margin-top to Home sections
* add top padding where needed so natural scroll positions do not clip headings
* ensure every section starts fully visible below the header
* validate after scrolling, not only on first paint

Do not remove legally required disclaimer text. Fix layout spacing around it.

Acceptance:

At 390px, every section heading is fully visible when the section begins.

⸻

P0 Fix 2 — Replace Bottom App-Tab Dock With Premium Mobile Conversion Dock

Current problem:

The bottom dock still looks like:

Call | Book | Upload

Three equal tabs is not premium and it covers content.

Required redesign:

Upload must be dominant.

Preferred mobile dock:

[Upload Statement — Free]
Call · Book

or:

Call    [Upload Statement — Free]    Book

but Upload must clearly be primary.

Requirements:

* no three equal-width app-tab columns
* compact height
* safe-area aware
* appears only after hero CTA is out of view or after a scroll threshold
* adds enough bottom padding to Home content
* never covers cards, fields, CTAs, or text
* preserves all tracking handlers
* preserves all destinations
* works on 390px and 430px

Add a data or class hook if needed so page sections can reserve bottom space.

Acceptance:

At 390px, content can scroll fully above the dock with at least 24px breathing room.

⸻

P0 Fix 3 — Chat Bubble Must Not Cover Content

Current problem:

Chat bubble is covering important text and CTAs in almost every screenshot.

Fix requirements:

Choose one safe strategy:

Preferred

Hide/minimize floating chat on mobile when sticky CTA is visible, and expose chat through a smaller secondary affordance.

Acceptable

Move chat above the dock with a large enough offset and auto-hide it over dense/interactable sections.

Also acceptable

Disable floating chat on Home mobile and keep chat available from menu/footer/contact area.

Requirements:

* chat cannot overlap Upload
* chat cannot overlap Book button
* chat cannot overlap report rows
* chat cannot overlap calculator fields/results
* chat cannot overlap terminal table/cards
* chat cannot overlap testimonial/vertical cards
* chat cannot overlap final CTA

Acceptance:

Chat never covers readable content or conversion controls on 390px Home screenshots.

If chat and sticky dock cannot coexist cleanly, prioritize the conversion dock and hide/minimize chat on Home mobile.

⸻

P0 Fix 4 — Add Real Mobile Bottom Spacing Contract

Current problem:

Content continues underneath the dock as if no fixed bottom UI exists.

Fix requirements:

* add mobile bottom padding to Home main/page wrapper equal to dock height + safe-area + browser breathing room
* make cards/sections scroll above the dock
* ensure final CTA/footer are not hidden
* ensure form controls and table/card bottoms are not behind dock

Acceptance:

The bottom of every section can be fully viewed above the dock.

⸻

P0 Fix 5 — Mobile Content Diet

The mobile Home page is still too long and too dense.

Desktop can be richer. Mobile must be ruthless.

Classify every Home section as one of:

keep on mobile
compress on mobile
accordion on mobile
carousel on mobile
desktop-only
move lower on mobile
remove

Do not stack the full desktop page.

Mobile priority order should be:

1. Hero
2. Compact proof strip
3. Problem/red flags
4. What the review includes
5. How it works
6. Calculator / rate check
7. One testimonial/proof section
8. Final CTA

Everything else must be compressed, moved lower, hidden on mobile, or linked out.
