Required pattern

const recentSends = Array.isArray(data?.recentSends) ? data!.recentSends : [];

const recentSends = Array.isArray(operatorData?.recentSends)
  ? operatorData.recentSends
  : [];

data!
as any
as SomeType[]

unless there is no safer alternative.

Conditional rendering guard

If a list is rendered from a normalized local variable, the conditional should also use that normalized variable.

Bad:

{data?.recentSends?.length ? (
  recentSends.map(...)
) : (
  <EmptyState />
)}

Good:

{recentSends.length > 0 ? (
  recentSends.map(...)
) : (
  <EmptyState />
)}

The same rule applies to .filter(), .slice(), counts, badges, and empty-state checks.
