TRUE ROOT CAUSES
Why all compliance dry-run tests fail
Migration 0047 has not been applied. The Drizzle schema has opted_out_email but the live DB does not. Because Drizzle ORM generates SELECT and INSERT statements using the schema, both reads and writes against the contacts table fail at the PostgreSQL layer, which cascades into every feature that touches contacts: sequence worker, contactability engine, GHL sync, dashboard stats.

Fix: Run npx tsx scripts/migrate.ts (or let server/db-migrate.ts apply it on next restart). Single line, no data loss. Takes < 1 second.

Why the sequence worker would also fail (even without the test scripts)
The sequence worker calls storage.getContact(enrollment.contactId) at sequence-worker.ts:305. Because the ORM SELECT includes all schema columns, including opted_out_email, it would return an error on Drizzle's query builder step, causing each enrollment tick to throw and be logged as an error.

Why SMS/Voice/Ringless cannot self-activate
The contactability engine enforces a feature-flag gate inside evaluateContactability at steps that precede PEWC checks:

contactability.ts:683 — SMS_ENABLED=false → blocked immediately
contactability.ts:689 — VOICE_AI_ENABLED=false → blocked immediately
contactability.ts:698 — RINGLESS_VM_ENABLED=false → blocked immediately
Even if a sequence had SMS steps, the worker's Gate (b) would block execution and write an audit log. No SMS/voice/RVM message can exit the system with the flags at their defaults.
