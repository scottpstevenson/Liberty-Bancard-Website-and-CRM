Final Addendum to #831 — Shared Email Preview + Safe Body Editor

Approved to build.

Preview accuracy rule

The preview must reflect the stored step content, not a prettier imagined send.

Allowed:

stored subject
stored body HTML
sample merge-tag substitution
clear preview-only compliance notice

Not allowed:

Liberty logo/header unless already in stored body HTML
real unsubscribe link
real unsubscribe token
fake footer that appears to be part of the sent email
send-time branding that the real send path does not apply

Sanitization rule

If using dangerouslySetInnerHTML, sanitize the final rendered HTML.

Preferred order:

1. escape sample merge-tag values
2. substitute merge tags into subject/body
3. sanitize resulting HTML
4. render preview

If no sanitizer exists, use a sandboxed iframe:

<iframe sandbox="" srcDoc={safePreviewHtml} />

Do not use sandbox="allow-scripts".

Kill line:

STOP if stored HTML can execute JavaScript in the dashboard preview.

Merge-tag handling

Support at least:

{{firstName}} → Alex
{{companyName}} → Your Business
{{businessName}} → Your Business
{{bookingLink}} → https://calendly.com/liberty-bancard/intro

Also apply sample substitution to the subject line preview.

Unknown merge tags should remain visible, not be deleted.

SMS/plain-text guard

If a step is SMS/plain text, preview it as plain text or safely escaped text.

Do not treat SMS body content as trusted HTML unless that is already how the app stores it.

Component scope

Create:

client/src/components/EmailPreviewModal.tsx

It should accept:

subject: string;
body: string;
mergeTagSamples?: Record<string, string>;

Optional but useful:

contentType?: "html" | "text";

Sequences.tsx scope

Allowed changes:

Write / Preview tabs for sequence step body editing
Preview eye button on sequence step cards
local modal state
shared preview component import

Do not change:

sequence activation
sequence enrollment
sequence worker
GHL sync/send path
contactability
unsubscribe/footer injection
daily cap
global kill switch
campaign editing
template backfill

If global TypeScript still has unrelated legacy errors, report them separately and confirm the touched files are clean.

Kill lines

STOP if raw stored HTML can execute scripts.
STOP if preview shows branding/footer elements that recipients do not actually receive.
STOP if real unsubscribe tokens are generated client-side.
STOP if unknown merge tags are stripped.
STOP if SMS/plain-text content is rendered as unsafe HTML.
STOP if this task touches send logic, GHL sync, enrollment, activation, contactability, compliance injection, daily caps, or global pause.
