The existing uniqueness rule is only:

```text

```

That is insufficient because separate source systems can reuse the same key. Change it to:

```text
(subject_type, source_system, subject_key)
```

Update every lookup and selection hash to include `source_system`.

Do not use ingestion time as source observation time. Add an append-only observation occurrence/attestation record containing:

* Source subject ID
* Payload hash
* Provenance hash
* Source event key
* Actual source-observed timestamp
* Ingested timestamp
* Timestamp provenance: `source`, `import`, or `ingestion_only`

An unchanged payload observed later must be able to renew freshness without mutating or replacing the original observation.

Qualification decisions must reference the exact occurrence/attestation—not merely the deduplicated payload.
