654 - Final Premium Mobile/Desktop UI Audit + Card System Repair

What & Why

The site is improved, but the mobile experience still does not feel premium or production-ready. The biggest remaining problems are not just sticky CTA overlap. Several report-style cards have broken internal layouts: text rolls off the card, status tokens overflow, labels are misaligned, nested card/table layouts are too dense, and the background “paper lines” make the UI feel cheap instead of polished.

This task is a final strict design/UI/UX pass across mobile and desktop, focused on making the site feel premium, trustworthy, aligned, responsive, and intentionally designed.

Do not change backend logic, upload logic, API behavior, form submission behavior, analytics, CRM integrations, compliance meaning, or legal copy. This is a frontend design/layout refinement only.

Primary goals

* Make the site feel premium, polished, and high-trust.
* Fix every mobile card layout that currently looks squeezed, misaligned, or broken.
* Remove the cheap “lined paper” look behind report cards.
* Ensure no text, token, badge, value, or label escapes its card.
* Reduce the giant blue sticky CTA dominance.
* Normalize spacing, typography, card hierarchy, labels, and mobile layouts.
* Preserve the core Liberty Bancard brand and business messaging.

P0 — Fix the broken report card layouts

1. Statement Fee Audit card: fix text overflow and token alignment

The Statement Fee Audit card currently has the clearest structural problem. In the row near “Savings opportunity,” the value/status text rolls off the right side of the card. This is not caused by the sticky CTA. The card itself is using a layout that does not fit mobile.

Fix the Statement Fee Audit card so every row is fully contained at 375px, 390px, and 430px.

Current problems to solve:

* “Identified”/status text escapes the right edge of the card.
* Row labels, tokens, and values do not align consistently.
* Some rows have label + token + value competing in one horizontal line.
* Red tokens are oversized and visually loud.
* The “On review” and “Identified” elements fight each other spatially.
* The value column has no safe max width.
* Long values do not wrap or stack gracefully.
* The card feels like a squeezed desktop table.

Required mobile layout:
Each row should be one of these patterns:

Preferred pattern A:

* Row label on the first line, left aligned.
* Status/value on the second line, left aligned or right aligned only if it fits.
* Use flex-wrap and min-w-0 so long text never escapes.

Example:
Effective rate
3.47% · Above benchmark

Monthly fixed fees
$127/mo · Recurring

Savings opportunity
Identified · On review

Preferred pattern B:

* Left side: row label
* Right side: value
* Status token below the row, not squeezed between label and value.

Do not keep a three-column mobile layout if it causes overflow.

Technical requirements:

* Add min-w-0 to flex/grid children where needed.
* Use break-words or whitespace-normal where needed.
* Avoid whitespace-nowrap on tokens/values unless the parent can safely contain them.
* Tokens should have max-width: 100%.
* Text inside tokens should not overflow.
* No row content should extend past card padding.
* Test with long labels and values.
* The card must not rely on overflow-hidden to hide broken content.

The giant blue sticky CTA bar still makes the page feel less premium. It is visually too dominant and competes with every section.

Preferred fix:

* Remove the persistent sticky CTA entirely on mobile.

Acceptable alternative:

* Replace it with a subtle floating CTA that appears only after the user scrolls past the hero.

If kept:

* Do not use a giant full-width blue dock.
* Do not use a thick navy tray.
* Use a smaller pill or compact bar.
* Height should be ~44–48px, not oversized.
* Max width should be constrained, centered, and visually refined.
* Hide it when hero CTAs are visible.
* Hide it when forms, report cards, FAQ, footer, or interactive sections are in view.
* It must never cover form fields, card content, buttons, footer links, or card bottoms.

Visual direction:

* In-page CTAs should carry the conversion.
* Sticky CTA should be subtle, not the loudest element on the page.
