# 3. Absolute safety boundaries

## No real outreach

This task must not:

* Send an email or SMS to a real contact.
* Enroll real contacts in campaigns or sequences.
* Unpause outbound globally or by channel.
* Clear production holds.
* Trigger a real GHL mutation.
* Trigger SMTP, Gmail, ZeroBounce, Serper, AI, enrichment or other paid-provider calls merely to manufacture evidence.
* Consume provider credits without explicit authorization.
* Create or modify production campaigns, workflows or contact assignments.
* Perform a destructive production cleanup, merge, backfill or data rewrite.

## Production data

Production access must be read-only unless a separately approved operation is explicitly required.

Never output:

* Credentials or secret values
* Full SSNs
* Bank-account or routing numbers
* Authentication tokens
* Full message bodies
* Raw sensitive intake payloads
* Unredacted recipient lists
* Provider API keys

Counts, redacted identifiers, hashes, booleans, age buckets and bounded aggregates are acceptable.

## Stateful and destructive tests

Any state-changing, failure-injection, concurrency, crash-recovery or provider-denial test must use:

* `NODE_ENV=test`
* A separately provisioned disposable PostgreSQL database
* `DATABASE_URL` exactly equal to `TEST_DATABASE_URL`
* A database name containing `test` or `ci`
* Verification through `SELECT current_database()`
* An isolated Redis namespace using a unique `TEST_REDIS_PREFIX`
* Fake/fail-fast provider transports
* Test-only accounts and contacts
* Cleanup in `finally`/trap paths

Never fall back to the Replit development or production database.

## Provider denial

For isolated testing:

* Set `GHL_TRANSPORT_FAILFAST=true`.
* Keep outbound globally paused unless a specific isolated test temporarily changes only test-owned state.
* Prevent SMTP and real email delivery.
* Do not provide real provider credentials.
* Disable unrelated workers/providers.
* Count attempted provider invocations.
* A blocked case passes only when provider invocation count remains zero.
* A failed network request is not equivalent to “no provider call.”
