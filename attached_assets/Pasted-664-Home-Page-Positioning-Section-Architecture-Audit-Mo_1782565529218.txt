664 — Home Page Positioning + Section Architecture Audit

Mode

READ-ONLY AUDIT FIRST.

Do not edit code. Do not build. Do not patch components yet.

The goal is to diagnose why the current Home page still does not feel like a premium credit card processing / merchant services company website, and produce a surgical rebuild plan.

⸻

Current Verdict

The Home page is not ready.

The current page is cleaner than before, but it still has major product-positioning and UX architecture problems:

It reads like a free statement review / bill analysis tool, not a full credit card processing and merchant services company.

Visible issues:

* hero title/subtitle do not clearly establish Liberty Bancard as a credit card processor / merchant services provider
* free statement review feels like the entire product instead of the entry point
* sections flow together on the same white/off-white canvas
* there are weak or missing visual breaks between major content chapters
* some cards/text are too small and read like admin/report UI
* terminal/setup section still feels disconnected from the overall merchant-services story
* platform/internal visibility section feels like a different SaaS product
* “Why Merchants Switch” and later sections start without clear section resets
* there appear to be two sticky chat/contact bubbles, one left and one right
* page rhythm is still repetitive: heading → cards → heading → cards, mostly on similar backgrounds
* both desktop and mobile need section architecture review before another build pass

⸻

Audit Goal

Produce a section-by-section diagnosis and rebuild plan that answers:

What should this Home page say?
What should the first-time visitor understand within 5 seconds?
Which sections are necessary?
Which sections are in the wrong order?
Which sections need stronger visual resets?
Which sections should be compressed, reframed, moved, or removed?
Which sticky components are duplicating?
What exact build task should be executed after audit?

Core Positioning Standard

The Home page should position Liberty Bancard as:

a premium credit card processing / merchant services company

not merely:

a free statement audit tool

The free statement review should be framed as:

the low-friction entry point into Liberty’s processing review, setup, and merchant services relationship

not as the entire product.

Within 5 seconds, a visitor should understand:

Liberty Bancard helps businesses accept payments, review processing costs, compare merchant-services options, set up terminals/POS, and get human account support.

    * payment processing

3. Section Break / Visual Rhythm Audit

For every major section, identify:

* current background/treatment
* whether it visually separates from previous section
* whether it feels like a new chapter
* whether spacing is too much or too little
* whether the section reads as premium or flat

Required output:

section treatment map

Example format:

Hero — light editorial ledger
What Liberty Does — deep navy service band
Pain Points — warm off-white red flag module
Review Deliverable — white report card on warm background
Processing Options — split light/dark product section
Terminal Setup — implementation module
Proof / Why Switch — dark credibility band
Final CTA — high-contrast navy conversion block

Hard audit question:

Where does the current page fail because it starts a new section on basically the same background?

⸻

4. Merchant Services Clarity Audit

statement audit / bill review only

5. Typography / Readability Audit

Review cards/tables/body text on desktop and mobile.

* table copy too dense
* card titles too weak
* labels overused
* mono text overused
* report-style components that feel too admin-like
