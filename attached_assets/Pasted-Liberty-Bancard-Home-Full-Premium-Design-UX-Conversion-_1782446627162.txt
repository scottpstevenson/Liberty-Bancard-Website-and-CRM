1. Art Direction Audit

Evaluate whether the page has a clear visual point of view.

The page should clearly communicate:

Liberty turns confusing processing statements into clear financial intelligence.

Pass criteria:

* the page feels like premium payment-forensics / statement intelligence
* the report/document system is visually memorable
* navy, Liberty blue, Liberty red, off-white, and mono report details feel intentional
* the page does not feel like generic fintech/SaaS
* the page does not feel like a plain bank brochure
* the page does not feel like “big serif headline on white”
* the creative direction remains coherent through the first several sections

Fail criteria:

* hero looks nice but generic
* report card looks like a table
* post-hero sections revert to old template styling
* colors feel random
* typography feels theatrical instead of authoritative
* there is no recognizable Liberty design language

Required Severity Levels

Use:

P0 — Must fix before approval

Examples:

* visual direction still generic
* mobile hero broken
* sticky CTA covers conversion action
* chat overlaps Upload
* unsupported major claim
* tracking/route broken
* Source Serif appears in dashboard/portal
* report card looks like flat table
* first scroll still old template

P1 — Fix before launch if possible

Examples:

* section feels weaker than rest
* spacing inconsistency
* claim needs softer wording
* CTA hierarchy not ideal
* mobile screenshot not premium enough

P2 — Polish

Examples:

* small alignment issue
* slightly weak icon
* minor copy improvement
* minor animation/spacing polish

P3 — Follow-up

Examples:

* deeper A/B testing
* later design system cleanup
* future section expansion
