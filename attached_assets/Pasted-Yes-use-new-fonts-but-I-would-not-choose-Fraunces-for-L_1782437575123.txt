Token direction

The agent is right that the base tokens are not the main problem. The page is ugly because Home.tsx is overriding the system with dark gradients, glow blobs, and the hero image.

But I would still refine the tokens.

Use this direction:

--background: warm off-white
--foreground: deep navy
--primary: Liberty navy
--accent: Liberty blue
--brand-red: Liberty red
--stat-negative: controlled red
--stat-positive: controlled green
--radius: 0.5rem
--shadow-card: restrained premium card shadow
--shadow-elevated: stronger hero/report card shadow

The radius change matters. 0.75rem feels soft/SaaS. 0.5rem feels sharper and more financial.
