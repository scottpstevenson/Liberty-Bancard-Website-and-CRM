What & Why

The current redesign is too safe.

It successfully removed the dark particle hero, glow blobs, glassmorphism, and yellow promo banner, but it did not replace them with a strong Liberty Bancard visual identity.

The page now feels like:

safe financial brochure
generic white landing page
oversized serif headline
plain buttons
flat report table

That is not acceptable.

Liberty Bancard needs a premium, sharp, high-trust merchant-payments page that feels designed, memorable, and conversion-focused.

This is a visual direction escalation, not a minor polish pass.

Core Visual Concept

Build the page around a premium “Statement Intelligence Report” system.

The hero should feel like the visitor is seeing a polished Liberty report, not just a marketing page.

Required visual motifs:

* document/report cards
* statement rows
* audit markers
* stamped sample labels
* precise blue/red accent lines
* subtle ledger/grid texture
* sharp navy blocks used intentionally
* Liberty logo colors used as a controlled system

Avoid:

* particle backgrounds
* generic gradients
* glow blobs
* glassmorphism
* giant empty white space
* cheap icon grids
* oversized unstructured serif text
* plain bordered cards everywhere

⸻

Hero Rebuild

The current hero is not approved.

Rebuild it again with stronger composition.

Desktop direction

Use a more editorial split layout:

* left side: sharp headline, short copy, CTA stack
* right side: layered statement/report card system
* background: warm off-white with subtle ledger/grid texture OR a controlled navy side panel
* brand accent: thin Liberty red/blue rule, not random color splashes
* report card should feel like the main visual product

The report card should not be a flat table. It should feel like a premium deliverable.

Include details like:

Liberty Statement Intelligence
Sample review
Effective Rate Audit
Markup Signals
Funding Timeline
Fee Drivers
Illustrative only

Mobile direction

Mobile must not feel like a giant text stack.

Requirements:

* headline fits cleanly without feeling cartoonishly large
* primary CTA visible without scrolling too far
* statement/report preview appears early enough to sell the concept
* no content hidden by sticky CTA/chat
* no weird overlap with the disclaimer/header
* no giant blank gaps

Suggested mobile headline sizing:

44px–52px max
line-height around 0.95–1.05
controlled wrapping

Do not use a huge serif block that looks like a magazine cover without the rest of the design system supporting it.

For this task, minimally fix the mobile first-screen experience:

Visual System Requirements

Typography

Source Serif 4 can stay for public marketing display, but use it with restraint.

Fix:

* oversized mobile headline
* awkward line breaks
* overly soft blog-like feeling

Use IBM Plex Sans for operational support text and labels.

Use IBM Plex Mono for statement/report data.

Color

Use:

* deep navy
* warm off-white
* Liberty blue
* Liberty red
* controlled green for opportunity only

Avoid:

* bright cyan glow
* washed-out gray everywhere
* generic blue SaaS gradients
* pale icon grids

Layout

The design needs more intentional density.

Avoid:

* giant blank white areas
* giant single-column stats
* massive vertical gaps
* cards that look copy-pasted
* sections that feel unrelated to each other
