- Dashboards/funnel analytics are production-only by default with explicit authorized non-production filters.
- Every KPI row is classifiable and aggregate reconciliation is deterministic.

2. Select/extend one canonical classification model and transition owner.
3. Add the next valid migration and compatibility behavior.
4. Make entity writers assign an explicit safe class.
5. Add audited operator transition/backfill mechanisms.
6. Apply production-default filters to all material metrics and cohorts.
7. Add reconciliation and production-path tests.
