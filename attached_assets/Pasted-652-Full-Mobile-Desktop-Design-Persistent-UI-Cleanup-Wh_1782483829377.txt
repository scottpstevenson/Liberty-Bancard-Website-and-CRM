652 - Full Mobile/Desktop Design + Persistent UI Cleanup

What & Why

The mobile experience has critical layout problems caused by too many persistent UI layers: a bulky multi-layer header, a legal/disclaimer strip pinned above the logo, a dark navy phone-number bar consuming the first viewport, an oversized sticky CTA tray, and a chat bubble that overlaps hero CTAs and form inputs.

This task surgically fixes those issues component-by-component and then performs a strict mobile/desktop UI polish pass for spacing, typography, card rhythm, section transitions, and responsive behavior.

Do not touch backend logic, API behavior, compliance meaning, upload behavior, form handling, or business rules.

Primary goal

Make the site feel clean, premium, fast, intentional, and easy to use on mobile.

Mobile should no longer feel like the first viewport is being consumed by header chrome, legal strips, sticky trays, and floating widgets.

Done looks like

Mobile at 375px, 390px, and 430px:

* No legal/disclaimer strip appears above the logo/nav.
* No dark navy phone-number bar appears above the mobile header.
* Mobile header contains only the Liberty Bancard logo and hamburger.
* Mobile header height is approximately 72–80px.
* Mobile logo max-width is approximately 220–250px.
* Hamburger is vertically centered and has a minimum 44px tap target.
* Header is white with a subtle border/shadow.
* Sticky bottom CTA is one compact button only: “Upload Statement — Free”.
* Sticky CTA height is approximately 52–56px, excluding safe-area padding.
* Sticky CTA does not appear while the hero CTA block is visible.
* Sticky CTA does not cover form inputs, submit buttons, FAQ rows, card bottoms, footer links, or legal text.
* Chat bubble does not overlap hero CTAs, sticky CTA, form fields, or buttons.
* No content is hidden behind fixed/sticky elements.
* No horizontal overflow.
* Section spacing is consistent and rhythmic.
* Cards, tables, accordions, proof blocks, forms, and CTA areas are readable and polished.

Desktop at 768px, 1024px, 1280px, and 1440px:

* Desktop header remains clean and balanced.
* Desktop may show phone number/nav CTA if already designed cleanly.
* Legal/disclaimer copy is in normal page flow, not pinned above nav.
* Sticky mobile CTA does not appear on desktop.
* Mobile-only removals do not break desktop layout.
* Section spacing, card grids, typography, and CTA hierarchy remain polished.

Out of scope

Do not:

* Rewrite core marketing copy except to shorten labels that break layout.
* Add savings claims, compliance claims, guarantees, or new legal claims.
* Remove required legal/disclaimer language entirely.
* Change backend/API/upload/form behavior.
* Replace the Liberty Bancard logo asset.
* Redesign the entire brand identity.
* Add new pages.
* Add more persistent sticky/fixed UI layers.

P0 — Persistent UI cleanup

1. Remove the mobile dark navy phone bar

In the Navbar/Header component, remove the dark navy phone-number bar from mobile.

On mobile, the top of the page should go directly to the compact white header containing only:

* logo
* hamburger

Phone number must remain accessible in:

* hamburger menu
* footer
* desktop header if already clean

Do not allow phone number to render above, on top of, or inside the legal/disclaimer strip.

2. Remove legal/disclaimer strip from the header on all breakpoints

The legal/disclaimer strip must not be pinned above the logo/nav on mobile or desktop.

Move the disclaimer text out of Navbar/Header entirely and into normal page flow.

Preferred placements:

* directly below the hero CTA/proof area,
* near the statement upload/review section,
* and/or in the footer/legal area.

Keep the disclaimer copy intact. Relocate it; do not delete it.

Style it as readable fine print:

* text-[12px] or text-xs
* line-height around 1.45–1.6
* muted but accessible contrast
* not fixed
* not sticky
* not above the logo/nav

Avoid using opacity so low that the disclaimer becomes hard to read.

3. Compact the mobile header

Mobile header target:

* height: 72–80px
* logo max-width: 220–250px
* hamburger tap target: at least 44px
* background: white
* subtle border-bottom or shadow
* no top legal bar
* no phone bar
* no extra navy fill
* no large empty top padding

Create or update CSS variables if helpful:

–mobile-header-height: 76px;
–mobile-dock-height: 72px;

Use these variables for scroll-margin-top, anchor offsets, and sticky positioning.

Update index.css scroll-margin-top values so anchor links no longer over-offset for the old oversized header.

4. Fix z-index and fixed-layer rules

Audit all persistent elements:

* header/nav
* sticky mobile CTA
* chat widget
* cookie consent if present
* exit-intent popup if present

Rules:

* Header is fixed/sticky at top.
* Sticky CTA is fixed at bottom on mobile only.
* Legal/disclaimer copy is normal page flow.
* Chat bubble must not cover CTAs/forms.
* Do not create additional sticky bars.
* No two fixed elements should overlap.
* Add iOS safe-area support where needed.

Use:
padding-bottom: calc(var(–mobile-dock-height) + env(safe-area-inset-bottom));

for page/footer areas where sticky CTA could otherwise cover content.

5. Replace sticky CTA tray with one compact button

Current issue: sticky tray is too tall because it includes Upload + Call + Book.

Replace mobile sticky tray with one compact primary button only:

“Upload Statement — Free”

Remove Call and Book from the sticky tray entirely.

Call and Book remain available in:

* hamburger menu
* footer
* relevant in-page CTAs

Sticky CTA specs:

* mobile only
* md:hidden
* one full-width button
* button height: 52–56px
* tray vertical padding: minimal
* safe-area padding included
* no second row
* no Call button
* no Book button

Visibility behavior:

* hide sticky CTA while hero CTA block is visible in the viewport
* show sticky CTA only after the user scrolls past the hero CTA area
* hide or reduce sticky CTA while focused inside form inputs if needed to prevent keyboard/input overlap

6. Fix chat bubble behavior

Simplest preferred solution:

* hide chat bubble on mobile entirely.

Alternative acceptable solution:

* show chat bubble only after hero section,
* position it above sticky CTA using bottom: calc(var(–mobile-dock-height) + 16px + env(safe-area-inset-bottom)),
* hide it when any form section is in view,
* hide it when it would overlap any CTA.

The chat bubble must never cover:

* hero CTA buttons
* upload buttons
* sticky CTA
* call/book buttons
* form fields
* form submit buttons
* accordion rows
* important card content

P1 — Hero polish

7. Tighten hero vertical rhythm

Audit spacing between:

* nav
* eyebrow/pill
* headline
* subheading
* CTA buttons
* proof chips/trust bullets
* hero visual
* disclaimer fine print

Remove excessive blank space. Make the first viewport feel intentional, not crowded by chrome.

8. Hero CTA hierarchy

Primary CTA should clearly dominate.
Secondary CTA should not feel equal to the primary CTA.

Mobile:

* primary CTA full-width is acceptable
* secondary CTA can be outline and slightly less visually heavy
* avoid two giant identical buttons

9. Hero proof chips/trust bullets

Current proof chips may wrap awkwardly.

Fix by using one of:

* 2-column compact mobile grid,
* shorter labels,
* inline proof row,
* or hide lower-priority chips on mobile.

Avoid awkward 3-line wrapping.

P1 — Global mobile spacing and rhythm

10. Normalize section padding

Audit every Home section.

Mobile targets:

* dense sections: 40–56px top/bottom
* standard sections: 56–72px top/bottom
* major transitions: 72–88px max

Desktop targets:

* standard sections: 88–120px top/bottom

Do not use a blind global reduction. Fix section-by-section.

11. Remove double gaps

Find adjacent sections where one has large bottom padding and the next has large top padding.

Reduce compounded dead zones around:

* hero → audit/proof area
* statement audit → pain points
* deliverables → keep breakdown
* analysis/how-it-works sections
* strategy → industries
* terminal/product section
* testimonials
* FAQ
* callback/contact form
* footer

12. Improve section boundaries

Avoid long runs of white-on-white or cream-on-cream with only blank space separating sections.

Use intentional alternation:

* white
* cream/off-white
* navy
* dotted/grid background where appropriate

Use dividers sparingly and consistently.

P1 — Typography and readability

23. Normalize heading scale

Hero can remain largest.

For mobile section headings:

* avoid 4–5 awkward lines
* avoid orphan words
* use responsive clamp/text sizes
* reduce especially long centered headings

Long headings should not feel cartoonishly large on mobile.

24. Body copy alignment

Long paragraphs should generally be left-aligned on mobile unless they are short hero-style intro text.

Avoid centered multi-line body copy that becomes hard to scan.

25. Contrast pass

Increase contrast on:

* disclaimers
* legal fine print
* captions
* metadata
* muted body copy
* labels
* card descriptions

Do not use extremely faint opacity for important legal/compliance text.

P2 — Visual consistency

26. Borders and shadows

Reduce overuse of thick dark borders where they feel heavy or less premium.

Use:

* subtle borders
* light shadows
* soft surfaces

Keep strong borders only where intentionally editorial or document-like.

27. Icons

Normalize:

* icon size
* stroke width
* icon container size
* icon color
* spacing around icons

28. Badges/pills

Badges should be:

* compact
* readable
* consistent in casing
* not styled like form inputs unless they are interactive

Avoid too many badge styles.

29. Product imagery

Ensure product images:

* crop correctly
* scale proportionally
* do not float in excessive empty space
* feel intentional on both mobile and desktop
