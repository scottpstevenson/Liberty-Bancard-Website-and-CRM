## Canonical authority/invariant model

| Concern                       | Canonical authority                                                                     | Current status                                     |
| ----------------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Global provider authorization | `OutboundPauseAuthority`                                                                | Exists; bypassed by mutation clients               |
| Contactability/suppression    | `ChannelOrchestrator` plus `evaluateContactability()`                                   | Exists; manual routes bypass it                    |
| GHL network mutation          | One mandatory GHL mutation adapter at the last local boundary                           | Missing; C-04                                      |
| Scheduled execution           | BullMQ/legacy scheduler for recurrence; mutation authority still enforced at final I/O  | Scheduler exists; pause model is contradictory     |
| Inflight ownership/fencing    | Durable inflight row containing actual authorized epoch and renewable lease             | Defective; C-06/C-07                               |
| Operation idempotency/outcome | Generic provider-mutation attempt ledger with stable occurrence key and `UNKNOWN` state | Missing; C-08                                      |
| Public-form delivery          | Durable queue occurrence after the local transaction                                    | Missing; C-09                                      |
| Destructive provider mutation | Delete-specific server authority plus durable saga/outcome                              | Missing; C-02                                      |
| Operational redaction         | Central structured sanitizer at console/audit/error persistence boundaries              | Missing; C-13                                      |
| Communication history         | `communication_events` as access-controlled business data                               | Exists; must not be confused with operational logs |
| Human authorization           | `requireRole`/dashboard role plus entity/resource scope                                 | Missing on toolkit SMS surface                     |
| Migration authority           | Additive migration after rechecking journal head; never `db:push`                       | Current head known; new design required            |

Schema cardinality must be designed as one logical business occurrence to one or more provider mutation attempts. A unique `ghlContactId` or owner column is not a valid idempotency model: the same provider resource participates in multiple contacts, deals, tags, workflows and retries. The sequence-only `outbound_send_log` cannot safely be reused as a generic one-to-one mutation table.

## Lifecycle and concurrency proof

| Scenario                                                    | Current repository behavior                                                                       | Required behavior                                                              | Status                    |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------- |
| Two workers claim the same mutation                         | Job-level lock exists, but manual/form paths and individual mutations lack a shared durable claim | Unique logical occurrence claim; one executor wins                             | OPEN                      |
| Worker loses job lease and later returns                    | Lock token fences job-status release only; provider writes do not carry the fence                 | Reject stale writer before every external attempt and result persistence       | OPEN                      |
| Authorized epoch is persisted                               | All registrations write `0`                                                                       | Persist the exact authorization epoch                                          | OPEN                      |
| Lease expires during provider retry                         | Inflight row expires after 60 seconds without heartbeat                                           | Renewable lease or bounded provider deadline; stale work rejected              | OPEN                      |
| DB unavailable during drain                                 | Count is treated as zero                                                                          | Fail closed; do not report drain completion                                    | OPEN                      |
| Drain times out                                             | Pause still commits with only local remaining count                                               | Explicit blocked/degraded disposition and full durable count                   | OPEN                      |
| Provider succeeds, process crashes before local persistence | Operation is retried without a generic durable UNKNOWN/reconciliation state                       | Persist UNKNOWN and reconcile by stable provider/idempotency key               | OPEN                      |
| 429 or transient 5xx                                        | Some clients retry; form calls may ignore the response entirely                                   | Typed retryable result with bounded backoff and preserved occurrence           | OPEN                      |
| 400/404 permanent result                                    | Often swallowed or classified as `skip`                                                           | Terminal/quarantine/manual-review reason, distinct from success                | OPEN                      |

| Local archive followed by GHL DELETE                        | HTTP success is returned before detached delete; restore does not recreate provider data          | Durable authorized delete workflow with confirmed result/compensation          | OPEN                      |
| Successful recurring GHL tick                               | BullMQ repeat remains scheduled                                                                   | Preserve next occurrence                                                       | CLOSED FROM REPO EVIDENCE |
| Failed task ages beyond two minutes                         | Falls out of normal selection; some skips enter process-local suppression                         | Durable retry/quarantine independent of current process lifetime               | OPEN                      |
