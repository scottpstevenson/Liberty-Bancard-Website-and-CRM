Content accuracy guard

Each packet may include industry-specific messaging, but do not invent unsupported financial facts.

Allowed:

common payment pain points by vertical
rep-friendly talking points
question prompts
statement-review angles
operational examples
generic illustrative ranges clearly labeled as assumptions

Not allowed:

guaranteed savings claims
made-up average ticket values presented as fact
made-up chargeback rates presented as fact
specific processor fee claims without evidence
medical/healthcare compliance claims
claims that Liberty will definitely reduce rates or win approvals

If using default assumptions, label them clearly:

Default assumption — verify against merchant statement
Illustrative only
Rep should confirm with current processing statement

Packet structure guard

Follow the existing packet format.
