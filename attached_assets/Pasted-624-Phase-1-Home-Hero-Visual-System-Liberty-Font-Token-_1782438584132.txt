What & Why

Replace the Liberty Bancard homepage’s generic dark-SaaS / AI-template visual language with a light-first premium financial-services system.

This is Phase 1 only.

It establishes the approved brand font stack and refined global design tokens, then rebuilds only the Home page top visual system:

* hero
* hero statement-analysis card
* inline promo/banner removal
* trust rows directly below the hero
* top Home content stack below the shared Navbar

This phase must not rebuild the full page. Later phases own:

* sticky CTA / chat overlap
* mid-page sections
* final CTA
* disclaimer consolidation
* shared header/footer shell work

Fonts

Approved font stack:

Marketing display: Source Serif 4

* partner portal

⸻

Safer Font Architecture

Because current global CSS may apply font-display to headings everywhere, use this safe strategy unless preflight proves a better existing marketing wrapper exists:

Global defaults

* font-body → IBM Plex Sans
* font-display → IBM Plex Sans by default, so dashboards/portals remain operational and readable
* font-mono → IBM Plex Mono

Marketing display

Add one explicit marketing display utility/class:

font-marketing-display

or a scoped wrapper:

.marketing-surface h1,
.marketing-surface h2,
.marketing-surface .marketing-heading

that uses Source Serif 4.

For Phase 1, apply this only to the Home hero/top marketing sections.

Do not attempt to globally convert every public/marketing page to Source Serif in this phase unless a verified PublicLayout / MarketingLayout wrapper exists and can be safely scoped.

Implementation Steps

Step 1 — Install / load fonts

Update the existing font import to load:

* Source Serif 4
* IBM Plex Sans
* IBM Plex Mono

Use efficient weights only.

Recommended weight coverage:

Source Serif 4: 600, 700
IBM Plex Sans: 400, 500, 600, 700
IBM Plex Mono: 400, 500, 600

Use display=swap.

Remove Outfit / DM Sans imports only after confirming they are no longer referenced.

Do not include or share font files directly.

⸻

Step 2 — Update Tailwind font families and CSS variables

Add font families:

font-body → IBM Plex Sans
font-display → IBM Plex Sans default
font-marketing-display → Source Serif 4

If the repo uses CSS variables for font names, wire them cleanly.

Do not globally set font-display to Source Serif 4 unless every operational shell override is verified.

Kill Lines

Stop and report before build if:

* the current font system cannot be identified.
* font-display is globally applied to dashboards and no safe operational override/wrapper can be identified.
* Source Serif 4 would appear in Operator Dashboard / CRM / merchant portal headings.
* the upload CTA tracking helper does not exist and adding tracking would require new analytics infrastructure.
* hero background classes/assets are shared across unrelated pages.
* removing the promo banner would affect other pages.
* Navbar/shared disclaimer changes would be required.
* SEO props would need to change.
* booking URL attribution would be removed.
* CTA tracking would be removed.
* radius change causes severe obvious breakage in dashboard/portal screenshots.
* any backend/API/route changes are required.
* the task would add stronger savings, uptime, zero-cost, or “beat your rate” claims.
