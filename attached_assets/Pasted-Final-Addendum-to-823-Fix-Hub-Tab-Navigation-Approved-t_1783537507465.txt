Final Addendum to #823 — Fix Hub Tab Navigation

Approved to build.

Scope

This is a mechanical fix only.

For every affected hub:

import { useSearch } from "wouter";

Then replace:

const activeTab = new URLSearchParams(window.location.search).get("tab") ?? defaultTab;

with:

const search = useSearch();
const activeTab = new URLSearchParams(search).get("tab") ?? defaultTab;

Keep the existing navigate() behavior intact.
