714 — Align Outscraper / Discovery Vertical Classification to Canonical Campaign Verticals

What & Why

The SDR discovery engine currently classifies merchant categories into coarse labels such as Auto, Salon/Spa, Healthcare, and Restaurant.

However, Liberty already has more granular campaign verticals and seeded sequence families, including distinct verticals such as:

Med Spa
Salon
Dental
Auto Repair
Restaurant

This creates a silent routing problem for Outscraper Google Maps pulls:

med spa / medical spa / botox → Salon/Spa
hair salon / barber / nail salon → Salon/Spa
dentist / dental clinic → Healthcare
auto repair / mechanic / tire shop → Auto

That is acceptable for rough discovery counts, but not acceptable once leads are imported, scored, promoted, or enrolled into vertical-specific SDR campaigns.

This task adds a canonical vertical mapping layer so discovery/imported leads can preserve granular vertical intent and route correctly.

⸻

Done Looks Like

* Outscraper categories map to canonical Liberty verticals before scoring/enrollment.
* med spa, medical spa, botox, aesthetics, injectables map to Med Spa.
* hair salon, barber, nail salon, beauty salon map to Salon.
* dentist, dental clinic, orthodontist, oral surgeon map to Dental.
* auto repair, mechanic, tire shop, body shop map to Auto Repair or the exact canonical automotive vertical used by seeded sequences.
* restaurant, bar, cafe, pizza, sushi, latin restaurant map to Restaurant.
* The original raw source category is preserved for audit/debug.
* Sequence routing uses the canonical campaign vertical, not the coarse classifier label.
* No existing discovery source breaks if category is unknown.

⸻
