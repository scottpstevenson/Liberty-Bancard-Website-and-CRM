# Update procedure:
#   1. Download https://raw.githubusercontent.com/disposable-email-domains/disposable-email-domains/master/disposable_email_blocklist.conf
#   2. Cross-reference against https://github.com/disposable-email-domains/disposable-email-domains (README exclusion list)
#   3. Remove any domain known to serve real end users (ISPs, national providers, universities)
#   4. Run: sort -u disposable_email_blocklist.conf > server/data/disposable-domains.txt
#   5. Update the "Committed" date above and commit.
#
