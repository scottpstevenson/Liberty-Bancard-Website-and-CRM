
## Update: mirror can drift independently of the gateway
`provider_controls.local_budget_units` (checked by `getSfpProviderReadiness`) and `serper_control.local_budget` (the real gateway ceiling that gates every live call) are two separate columns. Only the bounded SFP "arm pilot" route ever raised the mirror, a few units at a time — if the real gateway ceiling was raised through another path, the mirror could stay stuck far behind, making the SFP pipeline report `provider_budget_exhausted` against a gateway with ample headroom. Added `POST /api/admin/serper/resync-budget-mirror` (admin-only, audited) that sets the mirror to `GREATEST(current, serper_control.local_budget)` — never lowers, no raw SQL. Always check both columns when diagnosing an SFP "budget exhausted" report that seems wrong.
